# Ceno Mecha Autentico — Fixed Deploy Package

This package is structured correctly for GitHub + Vercel.

## What your repo root should contain
- package.json
- vite.config.js
- index.html
- src/
- public/

## Deploy
1. Upload the contents of this folder to the root of your GitHub repository.
2. Import the repo into Vercel.
3. Confirm:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist

## Branding
Replace `public/logo-placeholder.png` with your preferred logo file.
